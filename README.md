# Лабораторная работа №1: Статистический анализ потребительского спроса

## Описание
В работе проведён комплексный статистический анализ потребительского спроса клиентов виноторгового предприятия. Выполнена предварительная обработка данных (очистка от выбросов и пропусков, удаление невалидных записей), созданы категориальные переменные для сегментации по возрасту и доходу, рассчитаны индексы динамики потребительского спроса (Пааше, Ласпейреса, Фишера), проанализированы показатели центра, вариации и характера распределений ценовых и количественных показателей. Построены столбчатые диаграммы, диаграммы размаха и диаграммы рассеивания для визуализации структуры потребительских групп и динамики показателей. Выявлены и проанализированы 5 наиболее крупных потребительских сегментов по комбинации признаков (возраст, доход, семейный статус, образование).

## Технологии

- **dplyr** – обработка и агрегация данных

## Функциональность

### 1. Загрузка и подготовка данных
- Установка рабочей директории и загрузка исходных данных (`FinalData`).
- Удаление строк с пропущенными значениями (`na.omit`).

### 2. Очистка данных от выбросов
- Реализована функция `remove_outliers_iqr()` для удаления выбросов по методу межквартильного размаха (IQR).
- Очищены столбцы: `Year_Birth`, `Income`, `Price2014`, `Price2015`, `Quantity2015`.
- Удалены строки с невалидным семейным статусом `"Absurd"`.
- Удалены неиспользуемые уровни факторов (`droplevels`).
- Построены boxplot для визуального сравнения распределения `Price2015` до и после очистки.

### 3. Создание новых переменных
- **Возраст**: `Age = 2025 - Year_Birth`
- **Возрастные группы** (5 квантельных интервалов):
  - `Young`, `Young adults`, `Middle age`, `Adults`, `Elderly`
- **Группы доходов** (10 равных интервалов): `Income group 1` – `Income group 10`

### 4. Расчёт индексов динамики потребительского спроса
- Индивидуальные индексы цен и количества (2015 к 2014).
- **Индекс Пааше**:
  \[
  P = \frac{\sum p_1 q_1}{\sum p_1 q_0}
  \]
- **Индекс Ласпейреса**:
  \[
  L = \frac{\sum p_0 q_1}{\sum p_0 q_0}
  \]
- **Индекс Фишера**:
  \[
  F = \sqrt{P \cdot L}
  \]
- Результат: все индексы ≈ 1.079, что свидетельствует о росте спроса примерно на 7.9% в 2015 году.

### 5. Показатели центра распределений
- Для каждого количественного показателя (`Price2014`, `Price2015`, `Quantity2014`, `Quantity2015`) рассчитаны:
  - Среднее арифметическое
  - Медиана
- На основе гистограмм сделан вывод о близости распределений к нормальному.

### 6. Показатели вариации и размаха
- Реализована функция `calculate_variation_metrics()`, вычисляющая:
  - Размах
  - Дисперсию
  - Стандартное отклонение
  - Коэффициент вариации
  - Интерквартильный размах
  - Среднее абсолютное отклонение
- Вывод: цены имеют меньшую вариацию (≈4.6%), чем количество (≈14%).

### 7. Показатели характера распределений
- Реализована функция `calculate_distribution_metrics()`, вычисляющая:
  - Асимметрию (skewness)
  - Эксцесс (kurtosis)
  - Коэффициент дифференциации (отношение 9-го дециля к 1-му)
- Вывод: распределения близки к нормальным, слабая асимметрия, отрицательный эксцесс (более пологие распределения).

### 8. Визуализация
- **Столбчатые диаграммы (barplot)** для:
  - Распределения по возрастным группам
  - Распределения по группам доходов
  - Распределения по семейному статусу
  - Распределения по образованию
- **Диаграммы размаха (boxplot)** для:
  - Динамики цен (2014 vs 2015)
  - Динамики количества (2014 vs 2015)
- **Диаграммы рассеивания (ggplot2)**:
  - Зависимость "цена–количество" для 2014 и 2015 годов с цветовым разделением по годам

### 9. Анализ 5 самых крупных групп потребителей
- Создан составной признак `Consumer_Group = Age_Group | Income_Group | Marital_Status | Education`.
- Выявлены 5 наиболее многочисленных групп.
- Для каждой группы рассчитаны:
  - Численность
  - Средние цены и количества за 2014 и 2015 годы
  - Средний доход
- Построены столбчатые диаграммы для визуализации размеров групп и средних показателей.
- Результаты сохранены в `Tables/Group statistics.csv`.
